# CELEUS × Jev — evaluation results

Live site: **https://zhijianzhouml.github.io/CELEUS-JEV/** · Paper: https://arxiv.org/pdf/2606.20820 · Code: https://github.com/zyecs/celeus

This site reports how accurate TypeSafe's Jev model (`jev-1.13.0`) is on four fixed benchmark pools. It also compares two ways of measuring that accuracy with fewer model calls:

- **CELEUS**: adaptive sampling guided by a cheap CPU predictor, with a residual-corrected betting confidence sequence. No extra LLM, no GPU.
- **EVALUE**: the baseline. Uniform random sampling without replacement, with an exact hypergeometric confidence sequence.

Both methods ask Jev one case at a time. They stop once the accuracy interval is at most ±2 percentage points wide. Each benchmark gets a 98.75% anytime-valid interval, so the four together hold with at least 95% probability for each method.

## Headline result

Each method ran 3 times with different random seeds. Every run reached the ±2-point target.

| Benchmark | CELEUS questions (mean) | EVALUE questions (mean) | Fewer with CELEUS |
|---|---:|---:|---:|
| Arena | 4,913 | 8,713 | 43.6% |
| MMLU-ProX | 4,017 | 6,160 | 34.8% |
| HaluEval | 3,763 | 6,317 | 40.4% |
| AgentProcessBench | 2,253 | 3,347 | 32.7% |

CELEUS used fewer questions than EVALUE in all 12 run-by-run comparisons. Its fresh-run API cost was about 37% lower ($1.97 vs $3.13 per run).

Both JSON files are generated by the evaluation project (`run.py export` and `summarize_repeats.py`). They contain aggregate numbers only: no API keys, no raw benchmark examples, no model responses.

## Scope and caveats

- The intervals cover the frozen, eligible benchmark pools. They are not guarantees about future deployment data.
- Arena measures agreement with the recorded human vote (A, B, tie, or both bad). It is not an Elo rating.
- AgentProcessBench covers only steps whose request fits the size limit: 2,634 of 8,509 steps were too long.
- MMLU-ProX question 3787 is excluded in all 29 languages, because its two reference-answer fields disagree.
- One Arena input exceeded Jev's token limit. Jev cannot answer it, so it was scored as incorrect.
- The intervals come from run 1, fixed in advance. Runs 2 and 3 only inform the question counts.
- Costs are API token usage × the listed price (input $0.042 per million tokens). They are not invoices.
