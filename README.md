# CELEUS × Jev — evaluation results

Live site: **https://zhijianzhouml.github.io/CELEUS-JEV/** · Paper: https://arxiv.org/pdf/2606.20820 · Code: https://github.com/zyecs/celeus

This site reports how accurate TypeSafe's Jev model (`jev-1.13.0`) is on four fixed benchmark pools. It also shows how few model calls **CELEUS** needs to certify that accuracy. CELEUS combines adaptive sampling, guided by a cheap CPU predictor, with a residual-corrected betting confidence sequence. It needs no extra LLM and no GPU.

CELEUS asks Jev one case at a time. It stops once the accuracy interval is at most ±2 percentage points wide. Each benchmark gets a 98.75% anytime-valid interval, so the four together hold with at least 95% probability.

## Headline result

CELEUS ran 3 times with different random seeds, and every run reached the ±2-point target. The full pool is every eligible case, which is what a complete evaluation would have to ask.

| Benchmark | CELEUS questions (mean of 3 runs) | Full pool | Fewer questions than full pool |
|---|---:|---:|---:|
| Arena | 4,913 | 134,243 | 96.3% |
| MMLU-ProX | 4,017 | 340,982 | 98.8% |
| HaluEval | 3,763 | 30,000 | 87.5% |
| AgentProcessBench | 2,253 | 5,875 | 61.6% |
| **All four** | **14,947** | **511,100** | **97.1%** |

One CELEUS run over all four benchmarks costs about $1.97 in API usage.

## Files

| File | Content |
|---|---|
| `index.html` | The page: styles and script, with no external dependencies. |
| `data.json` | CELEUS run 1, the pre-declared main result: intervals, counts, costs, provenance. |
| `repeats.json` | CELEUS question counts for all 3 runs, with means, full-pool sizes and costs. |
| `comparisons.json` | Published scores of other LLMs (GPT, Claude, Gemini, DeepSeek, Qwen, Llama, …), copied from each benchmark's paper with source and table, plus setup notes. These models were not run by us. |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are. |

Both JSON files are generated by the evaluation project (`run.py export` and `summarize_repeats.py`). They contain aggregate numbers only: no API keys, no raw benchmark examples, no model responses.

## Scope and caveats

- The intervals cover the frozen, eligible benchmark pools. They are not guarantees about future deployment data.
- Arena measures agreement with the recorded human vote (A, B, tie, or both bad). It is not an Elo rating.
- AgentProcessBench covers only steps whose request fits the size limit: 2,634 of 8,509 steps were too long.
- MMLU-ProX question 3787 is excluded in all 29 languages, because its two reference-answer fields disagree.
- One Arena input exceeded Jev's token limit. Jev cannot answer it, so it was scored as incorrect.
- The intervals come from run 1, fixed in advance. Runs 2 and 3 only inform the question counts.
- Costs are API token usage × the listed price (input $0.042 per million tokens). They are not invoices.
