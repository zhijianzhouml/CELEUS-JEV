02 / EVERY NUMBER

Evaluation summary

CELEUS ran three times with different random seeds, always to the same ±2-point precision. Questions and cost are compared with asking Jev every case in the full pool; the accuracy interval is from run 1, the pre-declared main result.

Four benchmarks
Click a benchmark for its source revision, filtering, stopping rule and accounting. Means use only complete sets of runs that all reached the precision target. Full pool = every eligible case; full-pool cost = pool size × average API cost per question in a uniform random sample of the pool (the full pool was not actually run). Cost per run = API usage of every answer a run used × the listed price; later runs reused saved answers, so the money actually spent was lower. The familywise claim covers the four primary pool means only.
