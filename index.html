Metric definitions & reproducibility

What is being certified?

The mean of a prespecified bounded performance score for each fixed benchmark pool. Benchmarks can use different score definitions; this page does not average them into one overall score.

What does “per pool case” mean?

Total certification cost or wall time, normalized by the full pool size N. It is not the cost or latency of a queried API request. CELEUS cost includes target calls, surrogate inference, and orchestration overhead.

Where do the intervals come from?

This dashboard displays imported estimates and interval endpoints. It does not derive confidence intervals from one run’s totals. Resource uncertainty needs its own valid estimator or repeated-run protocol; measured baselines are shown as reference points.

How are savings compared?

Savings = full-evaluation total − CELEUS total. Negative savings remain negative. Estimated and measured baselines must be identified, and runtime comparisons must use comparable concurrency and caching. Offline replay is not a new API saving.

“Certified” is conditional on the supplied statistical protocol. A 95% interval for each metric does not automatically provide 95% simultaneous coverage across every benchmark and metric.
